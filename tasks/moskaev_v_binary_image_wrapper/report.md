Построение выпуклой оболочки для компонент бинарного изображения
Студент: Москaев Владимир, группа 3823Б1ПМоп3

Технология:SEQ|MPI

Вариант: 32

1. Введение
Цель работы — реализация эффективного алгоритма построения выпуклой оболочки для компонент связности бинарного изображения с использованием последовательной (SEQ) и параллельной (MPI) версий для обработки изображений.

2. Постановка задачи
Формальная постановка:
Для заданного бинарного изображения размером width × height необходимо:

Найти все компоненты связности (объекты), состоящие из пикселей со значением 1

Для каждой компоненты, содержащей не менее 3 точек, построить выпуклую оболочку

Вернуть список оболочек в виде упорядоченных точек

Входные данные:

Целочисленный вектор формата [width, height, pixel1, pixel2, ..., pixelN]

width, height — размеры изображения (положительные целые числа)

pixel_i — значение пикселя (0 — фон, 1 — объект)

Общее количество элементов: N = width × height + 2

Выходные данные:

Вектор векторов пар координат (x, y)

Каждый внутренний вектор представляет выпуклую оболочку одного объекта

Порядок точек соответствует обходу оболочки по часовой или против часовой стрелки

Ограничения:

Изображение бинарное (0/1)

Используется 8-связность для определения компонент

Объекты с менее чем 3 точками игнорируются

3. Базовый алгоритм (Последовательный)
Алгоритм состоит из трех основных этапов:

3.1. Поиск компонент связности (BFS/DFS)
pseudocode:
Для каждого пикселя (x, y):
    Если pixel(x, y) == 1 и не посещен:
        Запустить поиск в ширину/глубину с учетом 8-связности
        Сохранить все точки компоненты
        Если размер компоненты >= 3:
            Добавить в список объектов
3.2. Алгоритм Грэхема для построения выпуклой оболочки
Найти опорную точку — точку с минимальной y-координатой (при равенстве — минимальной x)

Сортировка по полярному углу: отсортировать все точки относительно опорной точки

Построение оболочки:

Использовать стек для хранения точек оболочки

Для каждой отсортированной точки:

Пока в стеке ≥ 2 точек и последние 2 точки с текущей образуют не левый поворот:

Удалить верхнюю точку из стека

Добавить текущую точку в стек

3.3. Вычисление векторного произведения
Для определения ориентации трех точек используется формула:

text
cross(O, A, B) = (A.x - O.x) * (B.y - O.y) - (A.y - O.y) * (B.x - O.x)
> 0 — левый поворот (против часовой стрелки)

< 0 — правый поворот (по часовой стрелке)

= 0 — точки коллинеарны

4. Схема параллелизации (MPI)
4.1. Распределение данных
Изображение делится по строкам между процессами MPI

Каждый процесс получает свою горизонтальную полосу изображения

text
Процесс 0: [строка 0 ... строка k-1]
Процесс 1: [строка k ... строка 2k-1]
...
Процесс N-1: [оставшиеся строки]
4.2. Коммуникационная модель
Распределение изображения: главный процесс (rank 0) рассылает данные

Сбор результатов: все процессы отправляют найденные компоненты на rank 0

4.3. Роли процессов
Rank 0: координатор, собирает результаты, строит финальные оболочки

Rank 1..N-1: рабочие процессы, обрабатывают свои полосы, находят локальные компоненты

Изображение считается бинарным

MPI: дополнительная память для буферов обмена
